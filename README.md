# AgentScope Rust

A community-driven Rust implementation inspired by
[AgentScope](https://github.com/agentscope-ai/agentscope).

> [!IMPORTANT]
> This project is at an early design stage and is not yet affiliated with or
> endorsed by the AgentScope maintainers.

## Status

The project skeleton is ready. Its scope, compatibility guarantees, and public
API are intentionally still under discussion.

## Development

The project uses Rust 1.85 or newer and the Rust 2024 edition.

```shell
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo test --all-features
```
